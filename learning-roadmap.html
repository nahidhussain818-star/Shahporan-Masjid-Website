How to stay sane

  1. Build, build, build. 70% building, 30% reading/watching.
  2. Get comfortable being stuck. Every dev Googles things daily. The skill is knowing what to search for.
  3. Don't switch courses constantly. Tutorial hell is real. Finish one before starting another.
  4. Ship small things often. Deploy something every week, even if tiny.
  5. Use the masjid project as a goal post. Every new concept: "could this improve the masjid site?"
  6. Take breaks. Coding is a marathon. Rested brains learn faster.
  7. Teach back. Explain what you learned to a non-coder. If you can't, you don't fully understand it yet.
